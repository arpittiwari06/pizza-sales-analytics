# 🍕 Pizza Sales Analysis using SQL & Power BI

## 📌 Project Overview

This project analyzes pizza sales data using **MySQL** for data analysis and **Power BI** for interactive visualization. The objective is to uncover valuable business insights related to sales performance, customer ordering behavior, product preferences, and revenue trends.

The project demonstrates an end-to-end analytics workflow by solving real-world business problems with SQL queries and presenting the results through an interactive Power BI dashboard.

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify customer ordering patterns.
- Determine peak ordering days and hours.
- Analyze monthly sales trends.
- Understand customer preferences by pizza category and size.
- Identify the top-performing pizzas based on sales.
- Build an interactive dashboard to support business decision-making.

---

## 📈 Key Insights

- Generated **₹817,860+** in total revenue.
- Processed **21,350** customer orders.
- Customers ordered an average of **2 pizzas per order**.
- Friday and Saturday recorded the highest order volume.
- Peak ordering hours were **12 PM–3 PM** and **6 PM–9 PM**.
- Classic pizzas contributed the highest share of sales.
- Large-sized pizzas were the most preferred by customers.
- Monthly sales analysis revealed seasonal variations in customer demand.
